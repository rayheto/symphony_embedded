# Symphony · Soft Glass 风格包 v1.0

## 目标与来源
把 Apple/iPadOS 的层级、材质分工和克制色彩转成 Symphony 的可复用设计标准。它是当前四页的可选视觉迭代，不改变业务布局与数据。所有色值、圆角和尺寸均为本项目建议，不是 Apple 官方参数，也未声称从网页像素精确取样。

参考：
- [Apple iPad 产品页面](https://www.apple.com/ipad/)：产品信息组织参考；官网属于产品展示页面，不直接搬用其大标题与营销留白。
- [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：区分控制层与内容层。
- [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)：玻璃效果放在导航和控制层，避免玻璃叠玻璃。
- [Apple Color](https://developer.apple.com/design/human-interface-guidelines/color)：保持内容与控件之间的可读性及对比。
核对日期：2026-09-15。官网浏览器视觉抓取超时；来源依据为官网可访问内容与 Apple 设计指导的检索内容，不声称完成官网逐像素复刻。

## 哪些东西才是可复用的标准
1. 标准参考图：对齐整体观感、材质、组件形态。
2. 精确 SVG 色板：可缩放，可直接读十六进制颜色。
3. JSON tokens / CSS：让后续页面得到相同数值。
4. 本文：组件规则、四页映射、提示词、验收标准。
优先级：业务数据与原四页设计提示词 > 本文与 tokens > 色板 > 生成参考图。参考图中的额外日期、头像缩写、评论数为生成偏差，不作为新增需求。

## 与已确认风格的差异
- 原圆角6–8px → 控件10px、卡片16px、大面板20px；组件层级不同，不统一套超大圆角。
- 原平面导航 → 可选白色轻磨砂导航；内容卡片依旧完全不透明。
- 原正文14px → 建议15px，辅助13px，日志13px，页标题28px、模块18px。工程页面不使用产品官网的巨型标题。
- 原中性按钮 → 每个操作区域最多一个蓝色主动作；其余为白色/灰色次级操作。
- 留白采用4/8/12/16/24/32刻度；桌面画布1440×900，外边距24，列间距16。保留8张任务首屏可见。
- 保留现有两行顶部导航和无左侧栏结构；参考图中的单行导航不作为布局变更。

## 颜色
精确值见 Symphony-Soft-Glass-palette.svg 与 tokens 文件。中性底面占主要面积；蓝色仅用于主动作、焦点和必要链接。
业务语义保持：待办灰；进行中琥珀；待审阅珊瑚；已完成紫；设备在线与执行成功绿。
已完成与在线是不同业务状态，不能为了统一色板混为一个状态。所有颜色配文字/形状。
警告正文 #946000 配 #FFF4DB；成功正文 #247A3C 配 #EDF7EF；不直接拿高亮黄绿作为小字。
生成图上的色块可能受光影与生成误差影响，禁止从生成图吸管取值替代 tokens。

## 材质与组件
- 画布：平坦 #F5F5F7。
- 卡片/证据/日志：不透明；日志使用内嵌灰底，不用透明玻璃。
- 顶部导航：白色88%不透明度、16px背景模糊；底下无可见内容时仍要清晰，禁止额外彩色壁纸制造反光。
- 不支持模糊或用户要求降低透明度时使用纯白。CSS模糊只是Web近似效果，不是原生Liquid Glass实现。
- 普通卡片16px圆角、16px内边距、极浅阴影；同一层级阴影一致。
- 主按钮36px高、蓝底白字；触控模式交互热区至少44px。次按钮白底深字，危险动作才使用危险色。
- 分段控件浅灰轨道、白色选中项；不做所有选项蓝色填充。图标统一线宽和尺寸。
- 交互状态必须包含默认、悬停、按下、键盘焦点、禁用、加载。禁用不仅降低透明度，还须真实禁止动作。
- 动效160ms，以轻微颜色/透明度变化为主；尊重减少动态效果设置。

## 四页怎么套用
### Issues
保持四列和全部8张卡片、编号、标题、标签、负责人、更新时间。增大圆角、柔化材质，负责人仍是文字，不新增头像/评论数/日期。可选蓝色新建按钮。保留顶部筛选和显示。
### 调查与证据
保持60/40双栏；左侧判断、调查时间线、下一步，右侧实底证据面板。最新节点是10:36，不更改时间线进度。假设未证实、事件待核验、未真机复测、未审阅始终可见。
### 设备与串口
保持设备表格与65/35详情布局；表格轻分隔，日志实底高可读。在线、采集中、复测未完成分别表示，不被装饰合并。不要给每一个属性独立套卡片。
### 方案审阅
保持64/36双栏与当前/拟议方案并排对比。两方案用浅选中底与单选标识；采用方案为唯一蓝色主动作。已记录、已停止、尚未执行维持不同回执。选中A不等于已经采用。

## 可直接复用的设计提示词
请基于 Symphony Soft Glass v1.0 风格包设计【页面名称】。
同时参考标准参考图、精确SVG色板、tokens文件及该页面既有业务规范。
保留原页面所有字段、状态语义和动作。1440×900正常桌面视口；正文15px、辅助13px、日志13px；两行顶部导航，无左侧大侧栏。
视觉采用中性浅灰画布、白色不透明内容面板、克制的蓝色主动作、16px卡片圆角、10px控件圆角与轻阴影。只有导航允许轻磨砂，日志、证据、文字内容不得透明。使用系统无衬线字体，不使用衬线、彩虹玻璃或大面积渐变。
状态使用本项目既有映射；提醒文字必须清楚。依据与未验证提示不能折叠掉。组件尺寸、间距、颜色以tokens和规范为准，不从生成图猜测。
不新增业务数据、头像、统计或装饰。交付正常尺寸单页，附默认/焦点/加载/空状态说明。生成图只作视觉验证；代码落地以字段清单与参数为准。

## 验收
- 第一眼能分清标题、主要内容、辅助信息、主要动作。
- 1440×900下看板8卡可见；详情在必要时滚动，禁止无限缩小文字。
- 正文对比目标4.5:1，关键交互边界目标3:1；实现后在实际背景上检测。
- 字段逐项对照原 Symphony-design-prompt.md，无遗漏、无新增假数据。
- 玻璃不重叠、日志不透明、状态不只用颜色。
- 四页共用组件与tokens，避免每次生成都重新猜色值。
- 本版仅定义浅色主题；深色主题需独立校验，不机械反色。
