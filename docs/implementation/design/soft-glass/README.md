# Symphony Soft Glass · 四界面设计交付

版本：2026-09-15 / v1.0

## 从这里开始
1. 打开 previews/ 查看四张独立桌面 PNG：01 看板、02 调查与证据、03 设备与串口、04 方案审阅。
2. 阅读 design/Symphony-Soft-Glass-guide.md，使用色板、JSON 变量与 CSS 作为实现依据。
3. 查看 design/Symphony-design-prompt.md 获取四页完整字段与业务状态。
4. prompts/ 包含各页面实际图像生成提示词与看板时间纠正提示词，便于后续重绘。

## 优先级
- 业务字段和状态：以 Symphony-design-prompt.md 为准。
- 视觉参数：以 Soft Glass guide、tokens、CSS 为准，覆盖原业务文档中旧版字号、圆角与按钮颜色。
- PNG：用于审阅布局与视觉方向，不作为精确取色、逐字数据或可执行交互依据。
- 标准参考图：仅用于审美参考，里面的额外头像/日期/评论数不属于产品需求。

## 交付范围
四张图片均为正常桌面比例，原始分辨率见 manifest.json。文件为内置 imagegen 生成的位图预览；本包不包含可交互应用、Figma源文件或后端实现。CSS是设计变量和基础样式示例，不是完整页面实现。

## 已检查及落地校对
- 看板包含8张卡片，按3/3/1/1分列；EMB-42时间已纠正为2分钟前。
- 调查页最新节点为10:36；保留假设未证实、事件待核验、尚未完成真机复测及未审阅。
- 设备页保留设备列表、七行日志、占用与验证范围；在线不表示验证通过。
- 审阅页区分已记录、已停止、尚未执行；默认选中A不表示已经采用。
- 图像生成仍存在局部呈现差异：设备页串口页签是蓝色下划线，实现时统一为规范中的浅灰分段选中态；调查页“要求补充证据”须做成真正按钮，避免图中呈现为普通文字；审阅页说明中的个别生成文字以字段文档为准。
- 四张PNG顶栏未显示H头像，实现时保留账号/设置入口，不因图片省略而删除功能。
- 实现需检查键盘焦点、触控热区、对比度、空状态、加载、错误状态；图片不能证明这些交互已完成。
