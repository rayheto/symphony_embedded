## 精确参数

`design/tokens.json`与`design/tokens.css`分别是新包原JSON/CSS的逐字节副本。JSON结构更新为colors/typography/spacing/radius/layout/material/motion；CSS变量统一使用`--sg-*`。实施中清除旧`--color-*`/`--font-*`等平行视觉真值；CSS是基础样式示例，完整组件与状态由实施任务完成。

| 项目 | 当前要求 |
|---|---|
| 画布/内容/日志底面 | #F5F5F7 / #FFFFFF / #EEEEF2；内容与日志不透明 |
| 文字/辅助/边框 | #1D1D1F / #686870 / #DEDEE3 |

| 正文/辅助/日志 | 15px / 13px / 13px等宽 |
| 页面标题/模块标题 | 28px / 18px |
| 控件/卡片/大面板圆角 | 10px / 16px / 20px |
| 主按钮/触控热区 | 36px高；触控模式热区至少44px |
| 布局 | 1440×900 CSS视口；外边距24px、列间距16px、卡片padding16px |
| 间距刻度 | 4/8/12/16/24/32px |
| 导航材质 | 白色88%不透明度、16px背景模糊；不叠加玻璃、彩色壁纸或装饰渐变 |
| 分段控件 | 浅灰轨道、白色选中项；图标统一尺寸线宽 |
| 动效 | 160ms轻微颜色/透明度变化，尊重减少动态效果 |

正文默认字重400，标题采用适度层次而非整体加粗；不靠缩小字号让8卡塞进首屏。记录浏览器实际fallback字体。次按钮白/灰底深字，蓝色仅用于主动作、焦点和必要链接；不把每个按钮都做蓝色。

## 状态、可读性与降级

Todo灰、InProgress琥珀、Review珊瑚、Done紫、Online/成功绿，各配文字与形状。警告 #946000 / #FFF4DB，成功 #247A3C / #EDF7EF，待审阅 #B04458 / #FCEFF2，完成 #6554B8 / #F1EEFA；精确值来自tokens。已完成与在线不能合并含义。
顶部保留两行导航，无左侧大栏；账号/设置入口必须可达。玻璃仅用于导航控制层，卡片/证据/日志全部不透明。不支持backdrop-filter或用户降低透明度时导航纯白；尊重prefers-reduced-motion，禁用状态真实阻止动作，默认/hover/pressed/focus/disabled/loading均需实现。
本版只定义浅色宿主主题，深色需另行设计/验收。正文实际背景对比目标4.5:1，关键交互边界目标3:1；细装饰边框不代替必要交互边界。若实测未达标，在保留基础色值的前提下增加合规focus/边界表达并记录，不虚称PNG已证明通过。
